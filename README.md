# University Management System

A desktop university management application built with Python and Tkinter.

## Features

- Add students, professors, and courses.
- Assign professors to courses.
- View course rosters and people records.

## Run

Use Python 3 with Tkinter installed, then run:

```powershell
python "import tkinter as tk.py"
```

The application stores records in memory only; they are cleared when the app closes. No third-party packages are required.
